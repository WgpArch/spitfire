    Keybindings Reference

    All keybinds use Mod4 (Super) as the primary modifier unless otherwise noted.

    Window Management

    Keybind Action
    Mod4 + q Close focused window
    Mod4 + j/k Focus next/prev window
    Mod4+Shift + j/k Swap next/prev window
    Mod4+Shift + grave Toggle scratchpad
    Mod4 + grave Toggle named scratch term

    Layouts

    Keybind Action
    Mod4 + t Tile layout
    Mod4 + f Fibonacci layout
    Mod4 + m Monocle layout
    Mod4+Shift + space Floating layout
    Mod4 + space Cycle layouts
    Mod4 + h/l Adjust master area size
    Mod4 + i/d Adjust master window count

    Workspaces

    Keybind Action
    Mod4 + 1-9 Focus workspace 1–9
    Mod1 + 1-9 Move window to ws 1–9
    Mod4 + F10-F12 Focus workspace 10–12
    Mod1 + F10-F12 Move window to ws 10–12

    Utilities

    Keybind Action
    Mod4+Shift + F3 Screenshot + notify
    Mod4 + Return Launch terminal
    Mod4+Shift + q Quit compositor
    Mod4+Shift + r Reload config
    Mod4+Shift + V Force paste (XWayland fix)

    Media Keys

    Key Action
    XF86AudioRaiseVol Volume up 5%
    XF86AudioLowerVol Volume down 5%
    XF86AudioMute Toggle mute
