# WgpArch spitfire Config

Welcome to the official documentation for my **spitfire** dotfiles, featuring a custom **Gold & Navy** theme with 12 native workspaces and sheer transparent Waybar.

## 🎯 Quick Start

1. Clone this repository: `git clone git@github.com:WgpArch/spitfire.git`
2. Copy configs: `cp -r spitfire/configs/spitfire ~/.config/spitfire`
3. Install dependencies (see [Installation](installation.md))
4. Launch spitfire from your display manager or terminal

## ✨ Key Features

-   **12 Workspaces:** Full support via number keys (1–9) and F-keys (F10–F12)
-   **Gold & Navy Theme:** Warm gold active borders (`#d4b483`) on deep navy background
-   **Native Screenshots:** `Mod4+Shift+F3` captures full-screen with notifications
-   **Rofi Integration:** Custom-styled launcher and powermenu matching the aesthetic
-   **Waybar Client Bar:** Sheer transparent pills with workspace indicators
