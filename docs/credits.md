# Credits & Acknowledgments

## Core Technologies

-   **spitfire**: Smithay-based dynamic tiling Wayland compositor ([GitHub](https://github.com/dani-77/spitfire))
-   **Waybar**: Highly customizable status bar for Wayland
-   **Rofi**: Window switcher, application launcher, and dmenu replacement
-   **grim**: Screenshot utility for Wayland compositors
-   **swaybg**: Wallpaper setter for Wayland

## Inspiration

-   **FHT Compositor**: Crimson Rain theme and 12-workspace patch served as foundational reference
-   **DWM Philosophy**: Minimalist, keyboard-driven workflow adapted to Lua-configurable environment
-   **Material Design**: Amber/gold palette inspiration for warm, accessible contrast

## Community

Thanks to the wlroots and Smithay communities for enabling secure, performant Wayland composition. Special thanks to @dani-77 for maintaining spitfire and responding to feature requests.
