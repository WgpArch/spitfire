# Look & Feel: Gold & Navy Theme

## Color Palette

| Role          | Value                  | Usage                          |
| ------------- | ---------------------- | ------------------------------ |
| Active Border | `#d4b483`              | Focused window highlight       |
| Inactive Bdr  | `#414868`              | Unfocused windows              |
| Sheer BG      | `rgba(30,37,50,0.85)`  | Waybar/tooltip backgrounds     |
| Text          | `#e8dcc5`              | Primary text color             |
| Hover/Accent  | `#d4b483`              | Interactive element highlights |
| Border Overlay| `rgba(232,220,197,0.2)`| Subtle border definition       |

## Design Principles

-   **Warm Contrast:** Gold accents against deep navy create visual hierarchy without harshness
-   **Sheer Transparency:** Layered opacity allows wallpaper to subtly show through UI elements
-   **Rounded Corners:** 12px radius on borders and UI elements for soft, modern aesthetic
-   **Consistent Spacing:** 20px inner gaps, 10px outer gaps maintain breathing room
